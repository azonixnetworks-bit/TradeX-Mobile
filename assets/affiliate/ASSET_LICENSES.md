Provider: [3Dicons](https://3dicons.co/) by Overlayz Studio / Vijay Verma. Each linked asset page identifies the asset as **CC0**.

- `illustrations/gift_box.webp` — [Gift Box](https://3dicons.co/icons/269bcd-gift-box)
- `illustrations/gift.webp` — [Gift](https://3dicons.co/icons/3f0398-gift)
- `illustrations/gold_coin.webp` — [3D Coin](https://3dicons.co/icons/b801dc-3d-coin)
- `illustrations/money.webp` — [Money](https://3dicons.co/icons/634add-money)
- `illustrations/crown.webp` — [Crown](https://3dicons.co/icons/634b4b-crown)
- `illustrations/wallet.webp` — [Wallet](https://3dicons.co/icons/7d956f-wallet)
- `illustrations/trophy.webp` — [Trophy](https://3dicons.co/icons/49654f-trophy)

Downloaded on 2026-10-25 from the individual asset preview URLs supplied by the provider. The original local WebP previews are retained unmodified. The following transparent, TradeX-themed PNG derivatives were generated from those CC0 references with OpenAI image generation and then resized locally for mobile use:

## TradeX Affiliate Dashboard component pack

The files prefixed with `illustrations/dashboard_` were supplied by the TradeX product owner in `TradeX_Affiliate_20_Transparent_Components.zip` on 2026-10-25. They are used only on the Affiliate Dashboard as visual artwork; all dynamic values and interactions remain native Flutter components.
